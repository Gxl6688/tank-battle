# 坦克大战 · Tank Battle

经典「坦克大战」风格的 HTML5 网页游戏，单文件实现、零依赖，打开即玩。

![游戏截图](screenshot.png)

## 玩法

- **方向键 / WASD** 移动
- **空格** 开火
- **P** 暂停
- **Enter** 开始 / 重新开始
- 消灭全部 20 辆敌方坦克即可过关，同时守住基地（下方金色雄鹰）不被摧毁

## 游戏特性

- 地形：砖墙（可破坏，两发摧毁）、钢墙（火力升满可摧毁）、水面、树林
- 5 种敌方坦克：普通 / 快速 / 火力 / 装甲 / 闪光奖励坦克
- 道具（击毁闪光坦克掉落）：⭐ 星星（提升火力）、🛡 头盔（护盾）、▲ 坦克（加命）、💣 手雷（全屏轰炸）、⏰ 时钟（冻结敌人）
- 关卡制，敌人数量和强度逐关提升
- WebAudio 音效、最高分本地记录（localStorage）

## 运行

直接用浏览器打开 `index.html` 即可，或部署到任意静态托管服务。

## 技术

纯 HTML + Canvas + JavaScript，无任何外部依赖。
